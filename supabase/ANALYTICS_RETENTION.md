## 이용 통계

- 적용 파일: `migrations/20261110_analytics_retention.sql`.
- 적용 상태: 2026-11-10 운영 DB 등록 완료. cron.job 작업 ID 1, active=true, 실행 사용자 postgres. 매일 예약 실행은 아직 관찰하지 않았으며 롤백 검증으로 정리 함수 동작을 확인했다.
- 매일 19:00 UTC(한국 04:00)에 90일 초과 이벤트와 마지막 활동이 90일을 초과한 플랜 작성 통계 요약을 정리한다. 저장 플랜 원본과 다른 테이블이다.
- 90일 경계는 유지하며, 다음 일일 실행 때 삭제하므로 실제 보관은 최대 약 91일이다.
- 오래된 세션도 최근 이벤트 또는 작성 통계가 참조하면 유지한다.
- 계정, 좋아요, 저장 플랜, 언어 설정은 이 작업 대상이 아니다.
- 관리자 통계 뷰는 원본 기록에서 계산한다. 정리 이후의 수치는 누적 평생 통계가 아니다.
- 일반 앱 사용자에게 정리 함수 실행 권한을 주지 않는다.
- 검증 파일: `tests/retention.sql`. 만료·경계·최근 참조 보존·서비스 데이터 분리·실행 권한을 확인하고 전체 변경을 롤백한다.
