  <p>현재 접속 국가 분석은 Google Analytics가 처리한 지역 통계를 활용하는 범위입니다. 이를 위해 ZEN WAY가 별도 IP 조회 업체를 추가하거나 원본 IP·추정 국가를 계정별 행동 이력으로 Supabase에 새로 저장하지 않습니다. 페이지 제공·보안을 위한 기존 접속 정보 처리와는 구분됩니다. 실제 지역 데이터의 수집 범위·가용성은 Google의 정책과 설정에 따르며 기기의 GPS 위치 권한을 요청하는 방식이 아닙니다.</p>
  <p>직접 작성한 이벤트 전송 코드는 검색 원문·별명·사진·이메일·주소·좌표·의견 본문을 속성에 넣지 않으며, 페이지 주소는 도메인과 경로로 제한합니다. 다만 GA의 자동·향상된 측정 설정은 별개이므로 자동 검색·폼·링크 이벤트의 실제 전송 범위를 확인해야 합니다. 맞춤 이벤트의 필터만으로 모든 외부 요청에 개인정보가 없다고 보장하지 않습니다.</p>
  <p>허용 전에는 GA 스크립트를 불러오지 않으며, 거부해도 기본 기능을 이용할 수 있습니다. <Link href="/profile">프로필의 이용 통계 설정</Link>에서 선택을 변경할 수 있습니다. 철회는 이후의 수집 중단을 위한 선택이며 이미 전송된 자료의 소급 삭제를 의미하지 않습니다. 별도의 삭제 요청은 문의처로 접수할 수 있습니다.</p>
  <p>2026-10-25 콘솔 확인 기록 기준 이벤트 데이터 보관은 2개월, 사용자 데이터 보관은 14개월이며 새 활동 발생 시 사용자 데이터 기간 재설정이 켜져 있습니다. 합산된 대부분의 표준 보고서에는 동일한 만료가 적용되지 않습니다. 이는 이번 문서 수정으로 변경한 설정이 아니며, 시행 전 실제 콘솔을 다시 확인합니다.</p>

   <li>운영자 전용 인증: 관리자 로그인에서 입력한 아이디·비밀번호를 자격 검증에 처리하며, 인증 쿠키로 접근 상태를 유지합니다. 현재 쿠키의 브라우저 만료 설정은 30일입니다. 일반 고객 계정 정보와 별개이고 실제 세션 보안 설정의 적정성은 별도 확인 대상입니다.</li>

  <p>Chrome·Safari·Edge 등 브라우저의 개인정보·사이트 데이터 설정에서 쿠키와 저장소를 확인·차단·삭제할 수 있습니다. 차단 시 로그인 유지·언어 기억·게스트 저장 등이 작동하지 않을 수 있습니다. 서버에 저장된 계정 데이터는 브라우저 저장소 삭제만으로 삭제되지 않으며, 로그아웃도 회원 탈퇴가 아닙니다.</p>

  <h2>7. 외부 처리업무와 제3자 제공</h2>
  <p>서비스 운영을 위한 위탁·저장·인증·호스팅과, 외부 제공자가 자신의 정책에 따라 처리하는 업무를 구분합니다. 법령상 근거 또는 필요한 동의 없이 본래 목적을 벗어나 개인정보를 제3자에게 제공하지 않습니다. 아래는 확인된 연결 서비스이며 실제 수탁 법인·재위탁 범위·독립적 처리 관계는 계약에 따라 최종 확정해야 합니다.</p>
  <ul>
   <li>Supabase: 계정 인증·세션과 계정별 저장·언어 설정·운영 집계, 활성화된 경우 의견 데이터 보관.</li>
   <li>Vercel: 웹 호스팅·페이지/API 요청 처리·배포·접속 및 보안 운영.</li>
   <li>Google·Apple: 선택한 소셜 로그인 제공. Google은 선택적 GA 통계(IP 기반 접속 국가·지역 추정 포함) 및 운영자 문의 메일 서비스에도 관여하며 각 목적의 처리는 구분됩니다.</li>
   <li>Mapbox: 지도 표시·지도 타일 및 관련 요청 처리. 지도에 표시되는 장소와 화면 영역은 관광 장소 정보이며 현재 웹은 기기의 GPS 위치 권한을 요청하는 기능을 제공하지 않습니다.</li>
   <li>한국관광공사: 관광 정보 API와 사진 서버(tong.visitkorea.or.kr). 사진을 불러오면 이용자 브라우저가 해당 서버에 직접 요청해 IP·브라우저·리퍼러 등 네트워크 정보가 전달될 수 있습니다. 계정 프로필이나 저장 계획 전체를 사진 서버에 전송하는 기능은 아닙니다.</li>
  </ul>
  <p>외부 지도·숙소·교통·예약 사이트 링크를 열면 목적지·출발지·조회 조건 등 링크에 포함된 값과 해당 요청의 기술정보가 전달될 수 있습니다. 그 사이트에서 새로 입력하는 개인정보·예약·결제에는 해당 사업자의 방침과 조건이 적용됩니다. 링크 연결을 계정 정보 전체의 제공과 동일하게 설명하지 않습니다.</p>

  <h2>8. 국외 이전</h2>
  <p>Supabase 프로젝트의 DB·Auth 리전은 현재 확인 기록상 대한민국 서울(ap-northeast-2)입니다. 그러나 공급자 공식 안내상 플랫폼 로그는 EU 데이터센터에서 처리되고 글로벌 운영·지원이 관여할 수 있으므로 모든 처리가 국내에 한정되는 것은 아닙니다. Vercel·Google·Apple·Mapbox·메일 서비스 역시 국외 처리가 수반될 수 있습니다.</p>
  <p>이전 항목, 국가, 시기·방법, 이전받는 법인과 연락처, 목적·보유 기간, 이전의 법적 근거, 거부 방법·효과를 제공자별로 확인 중입니다. 계정·저장 요청, 페이지·지도·이미지 요청, 통계 허용 후 전송, 문의 이메일 송수신 등 실제 처리 시점을 구분해 확정합니다. 단순히 전세계 인프라를 사용한다는 설명을 구체적인 국외 이전 고지의 대체로 사용하지 않습니다.</p>
  <p>계약 이행에 필요한 국외 처리위탁·보관 등 법령상 요건을 충족한 경우와 별도 동의가 필요한 경우를 구분합니다. 통계는 거부할 수 있고 지도·외부 링크는 이용하지 않을 수 있으나, 인증·호스팅 등 필수 처리의 거부는 관련 기능 이용에 영향을 줄 수 있습니다. 현재 이 항목은 국외 이전 고지의 확정본이 아닙니다.</p>

  <h2>9. 정보별 보유 기간</h2>
  <p>아래는 ZEN WAY의 보유 기준입니다. 공공기관 업무의 보존 기간을 그대로 적용하지 않으며, 별도 법정 의무가 없는 항목의 기간은 서비스 목적과 최소 보유 원칙을 고려한 운영 정책입니다. 새로 정한 단기 파기 작업은 원격 DB에 적용·검증하기 전까지 시행 완료로 표시하지 않습니다.</p>
  <ul>
   <li>계정 식별·인증 정보: 회원 탈퇴 시까지. 개별 인증 코드·세션은 제공자 설정에 따라 먼저 만료될 수 있습니다.</li>
   <li>저장 장소·추천 플랜·My Plan: 이용자가 항목을 삭제하거나 회원 탈퇴할 때까지.</li>
   <li>계정 언어 설정: 변경·삭제 또는 회원 탈퇴할 때까지.</li>
   <li>계정별 일일 운영 집계: UTC 기준 최근 30일만 보유하는 기준. 그 이전 기록은 일일 파기 대상으로 선정하며 탈퇴 시에는 해당 계정 기록도 삭제합니다.</li>
   <li>일반 의견·문의 본문, 처리 메모 및 이메일 첨부자료: 처리 완료 후 최대 30일이며, 미완료 건도 접수 후 최대 180일을 상한으로 정리합니다. 두 기준 중 먼저 도달한 시점을 파기 기준으로 삼습니다. 개선에 필요한 장기 참고 내용은 개인을 식별할 수 없도록 분리·정리하고 원문을 무기한 보관하지 않습니다.</li>
   <li>개인정보 열람·정정·삭제·처리정지 등 요청의 본문·확인 자료·처리 결과: 처리 완료 후 최대 30일. 이는 일반 문의의 미처리 상한으로 법정 처리 의무를 늦추거나 중단한다는 뜻이 아닙니다.</li>
   <li>브라우저 쿠키·로컬·세션 저장소: 제6항의 만료 또는 이용자의 삭제 시점까지.</li>
   <li>의견 접수 스팸 방지용 임시 IP 해시: 제3항의 메모리 처리 범위. DB 영구 보관 대상이 아닙니다.</li>
   <li>Google Analytics: IP 기반 추정 국가·지역을 활용한 이용 통계도 제5항의 콘솔 확인 기록 및 집계 보고서의 보유 범위에 따릅니다. 원본 IP를 ZEN WAY의 국가 분석용 계정 DB에 저장하는 보유 기간을 새로 설정하는 것은 아닙니다. 실제 설정 재확인 대상입니다.</li>
   <li>공급자의 접속·보안 로그와 백업: 운영 DB와 별도로 처리되며 실제 계약·설정별 기간을 확인 중입니다. Mapbox 공식 방침의 일반 IP 보관은 30일이며 보안 조사·법적 사유에 따라 예외가 있을 수 있습니다.</li>
  </ul>
  <p>법령상 보존 의무, 진행 중인 구체적인 분쟁·권리 요청 등으로 예외 보존이 필요한 경우에는 적용 근거·대상·필요 기간을 확인하고 목적을 제한해 분리 보관합니다. 단순히 향후 분쟁 가능성이 있다는 이유만으로 전체 자료를 무기한 보관하지 않습니다. 현재 예약·결제 거래를 직접 제공하지 않으므로 전자상거래 거래기록 보존 기간을 모든 회원 정보에 일괄 적용하지 않습니다.</p>

  <h2>10. 파기 절차와 방법</h2>
  <p>탈퇴·개별 삭제, 보유 기간 종료 또는 목적 달성으로 불필요해진 정보를 파기 대상으로 선정하고, 법령상 예외 보존 여부와 범위를 확인한 뒤 지체 없이 삭제합니다. 주기적으로 파기 대상을 확인하는 절차와 운영자 책임하의 처리 기록을 마련합니다.</p>
  <p>운영 DB에서는 해당 행과 계정 종속 정보를 삭제하고, 전자 파일·이메일·첨부자료는 복원이 되지 않도록 영구 삭제하는 기준으로 처리합니다. 이메일의 휴지통 이동만으로 파기를 완료한 것으로 보지 않습니다. 종이 출력물이 있는 경우 분쇄 등으로 파기합니다. 접근 권한이 없는 외부 제공자의 백업·로그가 즉시 모두 삭제된다고 보장하지 않으며, 제공자별 만료·삭제 절차를 따로 확인합니다.</p>
  <p>프로필의 회원 탈퇴는 최근 로그인 확인 및 최종 확인을 거칩니다. 정상 처리 시 ZEN WAY 계정과 계정 저장 항목을 운영 DB에서 삭제하며 Google·Apple 원본 계정 자체는 삭제하지 않습니다. 이 기능에 접근할 수 없거나 처리에 실패한 경우 문의 이메일로 요청할 수 있습니다.</p>
  <p>계정과 연결하지 않은 의견·이메일 문의·이미 전송한 분석 자료는 회원 탈퇴와 자동으로 함께 지워지는 정보가 아닙니다. 해당 정보를 특정하는 데 필요한 최소한의 접수 시각·내용 등을 문의처에 알려 별도 삭제를 요청할 수 있습니다. 다른 사람의 자료를 잘못 삭제하지 않도록 필요한 확인을 할 수 있습니다.</p>

  <h2>11. 정보주체와 대리인의 권리</h2>
  <p>개인정보 열람·정정·삭제·처리정지·동의 철회를 위 이메일로 요청할 수 있습니다. 법정대리인 또는 위임받은 대리인도 적법한 권한을 확인한 뒤 요청할 수 있습니다. 비밀번호나 일회용 인증코드는 확인 자료로 요구하지 않습니다.</p>
  <p>요청은 지체 없이 검토하며, 한국 개인정보 보호법에 따른 열람·정정·삭제·처리정지 요구는 원칙적으로 요구를 받은 날부터 10일 이내에 관련 법령에 따른 처리 결과를 안내합니다. 법령상 제한·거절·연기 사유가 있는 경우에는 그 사유와 이의제기 방법을 알리고 해당 절차를 따릅니다. 해외 이용자의 추가 권리나 별도 법정 기한이 적용되는 경우 그 요건을 함께 검토합니다.</p>
  <p>요청에 대한 결과에 이견이 있으면 같은 문의처로 재검토를 요청할 수 있습니다. 일반 의견 접수의 감사 안내는 개인정보 권리 요청의 처리 완료 통지가 아닙니다.</p>

  <h2>12. 개인정보 보호조치</h2>
  <p>계정 저장 자료는 인증된 사용자 식별자와 DB 접근 정책으로 구분하고, 일반 이용자의 고객 의견 전체 목록 접근은 허용하지 않는 구조로 관리합니다. 관리자 채널은 별도 인증 확인을 거치며 서버 전용 접근 키는 브라우저 코드에 포함하지 않습니다. 운영 배포에서는 HTTPS를 사용하고 접수·관리 API 응답의 캐시를 제한합니다.</p>
  <p>개인정보 접근 권한 최소화, 공급자·계약 관리, 비밀정보 보호, 접근·변경 기록 관리, 파기 확인과 유출 대응 절차를 운영 범위에 맞게 점검합니다. 일부 코드의 존재가 전체 보안조치의 검증 완료를 의미하지 않으며, 관리자 인증·DB 기록·주기적 파기·백업 처리는 공개 운영 전 추가 검증 대상입니다.</p>
