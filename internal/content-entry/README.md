# 행사 입력 화면 (2026-11-14)

관리자 입력 순서 검토용 화면: http://localhost:5001/local-admin/content

기본 정보 → 일정·운영시간 → 입장·예약 → 행사 내용 → 제품·가격 → 혜택·조건 → 외국인 안내 → 장소·교통 → 출처·검증 → 공개 상태.

- `fields.js`가 입력 필드와 순서의 원본이다. SQL 테이블의 물리적 컬럼 순서는 바꾸지 않는다.
- 5개 언어 입력, 요일/휴무/입장료/제품/옵션/혜택/결제/출처 반복 입력 지원.
- 초안은 현재 브라우저의 localStorage에 수동 저장한다. JSON 내보내기 지원.
- Supabase 조회·저장, 기존 행사 가져오기, 앱 공개는 아직 연결하지 않았다. 공개 상태는 설정안이다.
- 실행 중인 루트 개발 서버의 local-admin 파일로 복사했고, 기존 로컬/LAN 관리자 접근 제어를 유지한다.
- 확인: 브라우저에서 10개 단계 순서, 제품·옵션 추가, 언어 전환, 저장·새로고침 후 복원. 기존 관리자 접근 제어 테스트 12개 통과.
