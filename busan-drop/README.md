# BUSAN DROP — 모바일 프로토타입 스튜디오

## 실행

이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173/ 접속. index.html을 직접 열어도 기본 인터랙션이 작동합니다. 서버 실행 방식은 폰트 로딩과 클립보드 기능에 권장됩니다.

## 기획 해석

‘국내 대형 쇼핑 행사 사이트 찾기’는 현재 채팅입니다. 국내 대형 행사 모음 → 부산 방문 전 쇼핑 준비 → 무료 임베딩 폰트 → 블랙/따뜻한 포인트 컬러 → 할인 태그·여행 태그로 발전한 흐름을 반영했습니다. 지역 매장 현장 할인과 전국 쇼핑몰 할인은 동일한 혜택으로 가정하지 않았습니다. 현재 MVP는 여행 전 전국 쇼핑몰 탐색입니다.

390 × 844 CSS px, 좌우 여백 22px, SUIT 100–900(제공된 TTF 9종). 폰트는 assets/fonts에 로컬 임베딩했습니다. 기본 회색 와이어프레임과 #ecb617 / #ffd628 / #ff4632 컬러 버전을 같은 --accent 토큰으로 전환합니다. 배치와 기능은 동일합니다. 작은 실제 모바일 화면에서는 화면 폭에 맞추고 스튜디오 컨트롤을 상단에 배치합니다.

## 화면 및 인터랙션

- 인트로: 첨부 이미지의 떠 있는 태그·접힌 종이 모티프를 재해석. 임의 로딩 대기 없이 홈으로 이동.
- 홈: 3개 배너(점/터치 스와이프), 브랜드 퀵 링크, 카테고리별 혜택.
- 브랜드 목록: 이름 검색, 카테고리 필터 → 브랜드 상세 → 혜택 상세.
- 탐색: 브랜드·제목·카테고리 검색, 할인율 정렬, 검색 빈 상태.
- 상세: 예시 혜택 조건, 시연용 쿠폰 복사, 관련 혜택, 저장, 확인 시트 후 공식몰 새 탭.
- 저장: 가입 전에도 가능. 브라우저 localStorage로 재방문 시 유지.
- 회원가입: 이메일/8자 이상 비밀번호/데모 동의 검증. 실제 계정 생성 및 서버 전송 없음. 입력 이메일·비밀번호는 저장하지 않고 완료 상태만 저장.
- 마이: 체험 회원 상태, 로그아웃, 저장함, 서비스·알림 안내.
- 스튜디오: 화면별 치수·기능 설명, 화면 바로가기, 테마/포인트 변경, 인트로 재시작.

## 트래픽·재방문 설계 가설

가입 없는 탐색으로 초기 이탈을 줄이고, 저장으로 재방문 이유를 제공하며, 관련 혜택으로 내부 탐색을 연결합니다. 외부 이동 전 조건을 확인하도록 합니다. 성과는 실험으로 검증해야 하며, 실제 분석 도구나 개인정보 추적은 포함하지 않습니다. 색상으로 특정 호르몬 분비나 전환율 상승을 보장하지 않습니다.

## 검증

- `node --check app.js` 통과, 로컬 HTTP 200, SUIT 파일 9개 및 브라우저 로딩 확인.
- 브라우저에서 인트로→홈→저장, 올리브영 검색(1개 결과)→상세→공식몰 확인 시트의 실제 URL, 가입 동의→체험 회원 완료, 레드 테마 값 확인.
- 외부 몰에서 구매하거나 실제 계정을 생성하지 않았습니다.

## 제한

모든 할인율·기간·쿠폰은 시연용이며 실제 행사 데이터가 아닙니다. 검색은 내장 예시 데이터 대상입니다. 실제 인증, 실시간 행사 수집, 푸시 알림, 결제는 구현 범위에서 제외했습니다. 데스크톱 배치 명세는 스튜디오 바깥 패널에서 볼 수 있습니다. 브라우저 저장 데이터를 지우면 데모 상태가 초기화됩니다.
